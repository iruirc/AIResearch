Микросервисная архитектура позволяет:

1. Масштабировать отдельные компоненты независимо — если нагружен только сервис авторизации, масштабируем только его
2. Использовать разные технологии для разных сервисов — Python для ML, Go для высоконагруженных частей
3. Независимо деплоить изменения — команда может выкатить фикс без координации с другими
4. Изолировать сбои — падение одного сервиса не роняет всю систему
5. Организовать команды вокруг бизнес-доменов

Микросервисы идеальны для крупных распределённых команд (10+ разработчиков) и сложных систем с разными паттернами нагрузки.
