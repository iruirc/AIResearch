Python широко используется в data science благодаря библиотекам:
- NumPy для работы с массивами и математических операций
- Pandas для анализа и манипуляции данных
- Matplotlib и Seaborn для визуализации
- Scikit-learn для машинного обучения
- TensorFlow и PyTorch для глубокого обучения

Python стал стандартом де-факто в этой области благодаря простоте синтаксиса и богатой экосистеме. Jupyter Notebooks позволяют интерактивно работать с данными.
