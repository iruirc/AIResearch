Python был создан Гвидо ван Россумом в конце 1980-х годов. Название языка происходит от комедийной группы Monty Python. Первая версия Python 0.9.0 была выпущена в 1991 году.

Python использует отступы для обозначения блоков кода, что отличает его от других языков программирования. Версия Python 2.0 вышла в 2000 году, Python 3.0 — в 2008 году. Python 2 был официально прекращён в 2020 году.
