# Настройки реранкинга для тестирования

## Реранкинг результатов

| Параметр | Значение | Описание |
|----------|----------|----------|
| Использовать реранкинг | ✅ ВКЛ | Основная цель теста |
| Стратегия | `Cross-Encoder (LLM)` | Семантическое понимание контекста |
| Провайдер | `Ollama (Local)` | Локальный провайдер |
| Модель | `qwen2.5-coder:14b` | Генеративная LLM для оценки релевантности |
| Мин. скор релевантности | `5` | Не слишком строго, чтобы видеть "ловушки" |

## Общие параметры поиска

| Параметр | Значение | Описание |
|----------|----------|----------|
| Top-K результатов | `10` | Больше результатов для анализа (12 документов в базе) |
| Минимальный скор | `0.3` | Низкий порог, чтобы не отсечь документы-"ловушки" |

## Отладка

| Параметр | Значение | Описание |
|----------|----------|----------|
| Режим отладки RAG | ✅ ВКЛ | Показывать скоры и информацию о контексте |

## Примечания

- `nomic-embed-text:latest` — embedding модель, НЕ подходит для Cross-Encoder реранкинга
- `qwen2.5-coder:14b` — генеративная LLM, подходит для оценки релевантности
- Низкие пороги (скор 5, косинус 0.3) позволяют увидеть как работают "ranking traps" в тестовых запросах
