# Frontend-фреймворки

## Введение

Современная frontend-разработка основана на JavaScript-фреймворках, которые упрощают создание интерактивных пользовательских интерфейсов. Три доминирующих фреймворка: React, Vue.js и Angular.

## React

React — это библиотека для создания пользовательских интерфейсов, разработанная Facebook (Meta). Технически это не фреймворк, а библиотека для UI, но экосистема React создаёт полноценный фреймворк.

### Основные концепции React

**Компонентный подход:**
UI разбивается на независимые, переиспользуемые компоненты. Каждый компонент управляет своим состоянием и рендерит часть интерфейса.

**Virtual DOM:**
React использует виртуальное представление DOM для оптимизации обновлений. Изменения сначала применяются к Virtual DOM, затем эффективно синхронизируются с реальным DOM.

**JSX:**
Синтаксическое расширение JavaScript, позволяющее писать HTML-подобный код внутри JavaScript.

```jsx
function Welcome({ name }) {
  return <h1>Привет, {name}!</h1>;
}
```

**Hooks:**
Функции для использования состояния и других возможностей React в функциональных компонентах.

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Счётчик: ${count}`;
  }, [count]);

  return (
    <button onClick={() => setCount(count + 1)}>
      Нажато {count} раз
    </button>
  );
}
```

### Экосистема React

- **Next.js**: Фреймворк для SSR и статической генерации
- **Redux/Zustand**: Управление глобальным состоянием
- **React Router**: Клиентская маршрутизация
- **React Query/SWR**: Работа с серверными данными

### Когда использовать React:
- Сложные интерактивные приложения
- Когда нужна гибкость в выборе инструментов
- Большая экосистема и сообщество
- Мобильная разработка с React Native

## Vue.js

Vue.js — прогрессивный фреймворк для создания пользовательских интерфейсов. Создан Эваном Ю (бывший разработчик Google).

### Основные концепции Vue

**Реактивность:**
Vue автоматически отслеживает изменения данных и обновляет DOM.

**Single-File Components:**
Компоненты Vue объединяют шаблон, логику и стили в одном .vue файле.

```vue
<template>
  <div class="greeting">
    <h1>{{ message }}</h1>
    <button @click="reverseMessage">Перевернуть</button>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const message = ref('Привет, Vue!')

function reverseMessage() {
  message.value = message.value.split('').reverse().join('')
}
</script>

<style scoped>
.greeting {
  color: #42b883;
}
</style>
```

**Composition API (Vue 3):**
Новый способ организации логики компонентов, похожий на React Hooks.

**Директивы:**
Специальные атрибуты для DOM-манипуляций: v-if, v-for, v-model, v-on.

### Экосистема Vue

- **Nuxt.js**: Фреймворк для SSR и статической генерации
- **Pinia**: Официальный store (замена Vuex)
- **Vue Router**: Официальная маршрутизация
- **Vite**: Быстрый инструмент сборки (создан автором Vue)

### Когда использовать Vue:
- Когда важен низкий порог входа
- Постепенная интеграция в существующие проекты
- Небольшие и средние команды
- Когда нужна хорошая документация

## Angular

Angular — это полноценный фреймворк от Google для создания крупных приложений. Использует TypeScript по умолчанию.

### Основные концепции Angular

**Модульность:**
Приложение разделено на модули (NgModule), каждый из которых группирует связанные компоненты, сервисы и директивы.

**Dependency Injection:**
Встроенная система внедрения зависимостей для управления сервисами.

**TypeScript:**
Angular полностью написан на TypeScript и требует его использования.

**RxJS:**
Реактивное программирование с Observable для асинхронных операций.

```typescript
@Component({
  selector: 'app-hero-list',
  template: `
    <ul>
      <li *ngFor="let hero of heroes">
        {{ hero.name }}
      </li>
    </ul>
  `
})
export class HeroListComponent implements OnInit {
  heroes: Hero[] = [];

  constructor(private heroService: HeroService) {}

  ngOnInit() {
    this.heroService.getHeroes()
      .subscribe(heroes => this.heroes = heroes);
  }
}
```

### Экосистема Angular

- **Angular CLI**: Мощный инструмент командной строки
- **Angular Material**: UI-компоненты в стиле Material Design
- **NgRx**: Redux-подобное управление состоянием
- **Angular Universal**: Server-side rendering

### Когда использовать Angular:
- Крупные enterprise-приложения
- Команды с опытом в Java/C#
- Когда нужна строгая структура
- Долгосрочные проекты с поддержкой

## Сравнение фреймворков

| Критерий | React | Vue | Angular |
|----------|-------|-----|---------|
| Тип | Библиотека | Фреймворк | Фреймворк |
| Язык | JS/TS | JS/TS | TypeScript |
| Размер bundle | ~42KB | ~33KB | ~143KB |
| Кривая обучения | Средняя | Низкая | Высокая |
| Гибкость | Высокая | Средняя | Низкая |
| Структурированность | Низкая | Средняя | Высокая |

## Svelte

Svelte — это компилятор, который генерирует эффективный JavaScript-код во время сборки, а не в рантайме.

**Особенности:**
- Нет Virtual DOM — прямые обновления DOM
- Минимальный размер bundle
- Простой синтаксис
- SvelteKit для full-stack разработки

```svelte
<script>
  let count = 0;

  function increment() {
    count += 1;
  }
</script>

<button on:click={increment}>
  Нажато {count} раз
</button>
```

## Тренды и будущее

### Server Components (React)
Компоненты, которые рендерятся на сервере, уменьшая размер клиентского bundle.

### Islands Architecture
Частичная гидратация — только интерактивные части страницы загружают JavaScript.

### Astro
Фреймворк для контент-ориентированных сайтов с минимальным JavaScript.

### Qwik
Фреймворк с "resumability" — мгновенная интерактивность без гидратации.

## Рекомендации по выбору

1. **Большая команда, enterprise**: Angular
2. **Стартап, нужна скорость**: Vue или React
3. **Максимум вакансий**: React
4. **Минимальный bundle**: Svelte
5. **Постепенная интеграция**: Vue

## Заключение

Выбор фреймворка зависит от размера проекта, опыта команды и требований. React доминирует по популярности, Vue предлагает лучший опыт разработки для небольших команд, Angular подходит для крупных структурированных проектов.
